## Suggested Cleaning Frequency

| Frequency              | Example Tasks                                           |
| ---------------------- | ------------------------------------------------------- |
| Daily                  | Restrooms, waste bins, high-touch surfaces, floors      |
| Several times per week | Kitchens, common areas, detailed vacuuming              |
| Weekly                 | Detailed dusting, internal glass, doors and edges       |
| Monthly                | Less frequently accessed areas and maintenance          |
| Periodic               | Carpet cleaning, floor maintenance, specialist cleaning |

The appropriate frequency depends on the individual workplace and its cleaning requirements.

## Workplace Cleaning Checklist

### Office Areas

* [ ] Dust accessible surfaces
* [ ] Vacuum carpets
* [ ] Clean hard floors
* [ ] Empty waste bins
* [ ] Clean high-touch surfaces

### Kitchen Areas

* [ ] Clean countertops
* [ ] Clean sinks
* [ ] Clean tables
* [ ] Clean appliance surfaces
* [ ] Empty waste bins

### Restrooms

* [ ] Clean toilets
* [ ] Clean sinks
* [ ] Clean mirrors
* [ ] Clean floors
* [ ] Check supplies

### Common Areas

* [ ] Remove visible dirt and debris
* [ ] Clean high-touch points
* [ ] Vacuum or mop floors
* [ ] Check entrances

## High-Touch Areas

Businesses should consider including frequently touched surfaces in their regular cleaning routines.

Examples include:

* Door handles
* Light switches
* Handrails
* Elevator buttons
* Cabinet handles
* Shared equipment
* Countertops
* Taps
* Reception desks
* Meeting-room surfaces

Cleaning methods and frequencies should be appropriate for the workplace and the surfaces being maintained.

## Maintaining a Professional Workplace

Regular cleaning can help businesses maintain a more comfortable and professional environment.

A practical cleaning program should consider:

1. Workplace size
2. Number of occupants
3. Traffic levels
4. Type of business
5. Operating hours
6. Flooring and surface materials
7. Cleaning frequency
8. Areas requiring additional attention

A cleaning schedule should be reviewed periodically and adjusted when workplace requirements change.
